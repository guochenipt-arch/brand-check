# 品牌風險自我檢核表｜部署與引流手冊

國宸國際商標事務所 · Threads → 檢核表 → LINE 諮詢

---

## 一、上線前必改的 5 個地方

全部集中在 `index.html`，改完就能用。

| # | 位置 | 現在的值 | 要改成 |
|---|---|---|---|
| 1 | `<script>` 內 `CONFIG.siteUrl` | `https://check.guochenipt.com/` | 你的正式網址（**結尾要有斜線**） |
| 2 | `CONFIG.lineUrl` | `https://line.me/ti/p/umTOEprRU2` | 確認是現行的官方帳號連結 |
| 3 | `CONFIG.ga4Id` | 空字串 | GA4 評估 ID，例 `G-XXXXXXXXXX`（不填就不載入） |
| 4 | `CONFIG.metaPixelId` | 空字串 | Meta 像素 ID（不填就不載入） |
| 5 | `<head>` 內所有 `check.guochenipt.com` | 佔位網址 | 一次全部取代成正式網址（OG、canonical、JSON-LD 共 8 處） |

> 第 5 項最容易漏。OG 圖網址錯了，Threads 分享卡片就不會出圖。

## 二、GitHub Pages 部署

```bash
# 1. 建一個新 repo，例如 brand-check
git init
git add .
git commit -m "品牌風險自我檢核表"
git branch -M main
git remote add origin https://github.com/<你的帳號>/brand-check.git
git push -u origin main
```

2. Repo → **Settings → Pages** → Source 選 `main` / `root` → Save
3. 自訂網域：在 Pages 頁面填入 `check.guochenipt.com`，並到網域商（捕夢網）加一筆 CNAME 記錄指向 `<你的帳號>.github.io`
4. 勾選 **Enforce HTTPS**（Clipboard API 需要 HTTPS，複製功能才會生效）

檔案清單：

```
index.html      主頁（單檔，含所有 CSS/JS）
og.png          1200×630 分享卡片圖
404.html        錯誤頁
robots.txt
sitemap.xml
```

## 三、Threads 分享卡片檢查

貼文發出去之前，先用 **Facebook 分享偵錯工具** 抓一次快取：
`https://developers.facebook.com/tools/debug/`

輸入網址 → 點「再次抓取」→ 確認出現 `og.png` 的預覽圖。
Threads 與 Facebook 共用同一份快取，**改過 OG 圖之後一定要重抓**，否則會一直出舊圖。

## 四、Threads 引流實務

### 演算法注意事項
Threads 對含外部連結的貼文觸及會打折。實務上兩種做法：

- **A 案（推薦）**：正文純文字講痛點，**連結放在第一則回覆**，正文結尾寫「表單放留言區」
- **B 案**：連結放個人簡介，正文寫「連結在我主頁」

先跑兩週 A/B，看哪一種的 LINE 加入數高。

### 貼文文案（可直接用）

**① 改名比註冊貴**
> 有位客戶花了十八萬做完整套 CI，招牌都掛上去了。
>
> 我幫他查商標的時候，發現同樣的名字兩年前就有人註冊了。
>
> 最貴的從來不是商標規費，是改名。招牌、包材、名片、網域、社群帳號、印好的一整批貼紙，全部重來。
>
> 做了一份自我檢核表，五題、三十秒，先看看你的品牌現在站在哪一段。
> 不用填 Email、不用留電話。表單放留言區。

**② Google 迷思**
> 「我 Google 過了，沒有一樣的名字。」
>
> 這句話我一個月會聽到十幾次。
>
> 問題是商標權不看 Google，看的是智慧財產局的資料庫。裡面有大量已經註冊、但還沒實際上市的商標——你在網路上完全搜尋不到，它卻擋得住你。
>
> 你查得到的是市場，查不到的才是風險。

**③ 先申請主義**
> 商標不是誰先想到，是誰先送件。
>
> 你在評估「值不值得花這筆錢」的那三個月，別人可能已經在排隊了。
>
> 而且商標核准平均要等六到八個月，等你發現有問題才開始處理，時間根本不站在你這邊。

**④ 小品牌迷思**
> 「我的品牌還很小，應該不會有人搶吧？」
>
> 剛好相反。
>
> 大品牌被搶註，還能拿一整疊廣告投放紀錄、媒體報導去主張著名商標。小品牌沒有註冊、也湊不出足夠的使用事證，被搶走之後最難要回來。
>
> 規模小不是安全，是沒有防護。

**⑤ 直球介紹**
> 我是商標代理人，做了一份東西。
>
> 五個問題，測出你的品牌在商標保護上的缺口在哪一段。照商標審查基準寫的，不是心理測驗。
>
> 不用留 Email、不用填電話，結果直接跑在頁面上。
> 測完覺得有問題，再來問我就好。

### 節奏建議
一週 3 則，痛點型（①②④）和知識型（③）交錯，第五則每兩週補一次當作導流。留言區有人問問題就直接回，回完再附連結——那是轉換率最高的位置。

## 五、成效怎麼看

填了 GA4 或 Meta 像素 ID 之後，頁面會自動送出這些事件：

| 事件 | 意義 | Meta 標準事件對應 |
|---|---|---|
| `quiz_start` | 點了「開始檢核」 | ViewContent |
| `quiz_complete` | 看到結果頁（帶 `type`、`risk` 參數） | Lead |
| `line_click` | 點了 LINE 按鈕 | Contact |
| `share` | 用了分享功能 | — |

要看的兩個比率：

- **完成率** = `quiz_complete` ÷ `quiz_start`，低於 60% 表示題目太長或太難答
- **轉換率** = `line_click` ÷ `quiz_complete`，這是真正決定成敗的數字

`quiz_complete` 事件帶有 `type` 參數，可以看出流量進來的是哪一種人。如果「危機型」占比高，Threads 文案就往痛點加重；如果「穩健型」占比高，代表吸到的是已經有商標的客群，該把文案轉向類別完整性與海外佈局。
